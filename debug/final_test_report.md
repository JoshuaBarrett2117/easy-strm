### 5.1 高优先级问题

#### 问题1: 浏览115文件列表返回500错误
- **严重级别**: P1
- **影响范围**: 115云盘文件浏览功能
- **复现步骤**:
  1. 创建115云盘媒体源
  2. 点击"浏览"按钮
  3. 文件列表显示"No Data"
  4. 控制台出现500错误
- **可能原因**:
  - 115账号cookie无效或过期
  - 115 API访问失败
  - 目录路径不正确
- **建议修复**:
  - 检查115账号cookie有效性
  - 添加错误提示，引导用户重新登录115账号
  - 使用正确的目录ID

- **严重级别**: P2

  1. 查看媒体源列表
  2. 发现ID为2的媒体源名称显示为"?????-???"
- **可能原因**:
  - 数据库编码问题
  - 字符集不匹配
- **建议修复**:
  - 检查数据库字符集配置
  - 确保前端正确处理UTF-8编码

#### 问题3: 115云盘路径显示为"0"
- **严重级别**: P3
- **影响范围**: 用户体验
- **复现步骤**:

  2. 路径列显示为"0"
- **可能原因**:
  - 路径字段存储的是目录ID

- **建议修复**:
