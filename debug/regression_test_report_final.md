## 🔍 发现的问题

### 问题 1: 登录错误提示未显示

**问题描述**:
- 当使用错误密码登录时，前端没有显示错误提示
- 控制台显示 401 错误，但页面上没有错误消息

**根本原因**:
在 `request.js` 的响应拦截器中，401 错误会触发页面重定向到登录页，导致错误消息来不及显示：

```javascript
if (error.response && error.response.status === 401) {
  ElMessage.error('登录已过期，请重新登录')
  clearCredentials()
  redirectToLogin()  // 立即重定向，错误消息来不及显示
  return Promise.reject(new Error('登录已过期'))
}
```

**影响范围**: 登录功能

**建议修复**:
在登录页面，应该区分"登录失败"和"登录过期"两种情况：
- 登录失败：显示错误消息，不重定向
- 登录过期：显示错误消息，然后重定向

## ✅ 修复验证结果

### MediaManager.vue 修复验证

**修复内容**: 采用三级优先级提取错误信息
1. `error.response?.data?.error`（后端返回的具体错误信息）
2. `error.message`（HTTP错误信息）
3. 默认错误信息（兜底提示）

**验证结果**: ✅ **修复有效**

**证据**:
