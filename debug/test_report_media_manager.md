## 三、问题清单

### 问题1: 新增115云盘数据源失败 (P0 - 严重)

**问题描述**:
创建115云盘数据源时，后端返回500错误，导致无法正常创建数据源。

**复现步骤**:
1. 点击"新增媒体源"按钮
2. 填写名称: "Playwright测试115数据源"
3. 选择类型: "115云盘"
4. 选择关联账号: "115账号"
5. 填写路径: "0"
6. 点击"确定"按钮

**预期结果**:
成功创建115云盘数据源

**实际结果**:
后端返回500错误，创建失败

**错误日志**:
```
[error] Failed to load resource: the server responded with a status of 500 (Internal Server Error)
[error] [MediaManager] 提交媒体源失败: AxiosError: Request failed with status code 500
```

**建议修复方案**:
1. 检查后端日志，定位具体错误原因
2. 验证数据库表结构是否完整
3. 检查115账号关联逻辑
4. 添加详细的错误提示信息

## 四、UI/UX改进建议

### 4.1 错误提示优化
**当前问题**:
- 错误提示不够友好，仅显示"Request failed with status code 500"
- 用户无法了解具体错误原因

**改进建议**:
1. 添加中文错误提示
2. 根据错误类型提供不同的提示信息:
   - Cookie失效: "115账号登录已失效，请重新登录"
   - 网络错误: "网络连接失败，请检查网络设置"
   - 权限错误: "无权限访问该目录"
3. 提供"重试"按钮

### 4.2 加载状态优化
**当前问题**:
- 加载过程中没有明显的加载提示
- 用户无法判断操作是否成功

**改进建议**:
1. 添加Loading遮罩层
2. 显示加载进度提示
3. 添加骨架屏提升用户体验

### 4.3 表单验证优化
**当前问题**:
- 表单验证提示不够明显
- 用户不知道哪些字段是必填的

**改进建议**:
1. 必填字段添加红色星号标记
2. 实时验证用户输入
3. 提供字段说明提示

### 4.4 按钮交互优化
**当前问题**:
- 按钮点击后没有防抖处理
- 可能导致重复提交

**改进建议**:
1. 添加200ms防抖
2. 提交过程中禁用按钮
3. 显示提交中状态
