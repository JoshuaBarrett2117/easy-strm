# Easy-STRM 配置管理系统

## 项目概述

Easy-STRM 是一个综合的 STRM 配置管理系统，专门用于与 115 云盘 API 集成，实现目录树生成、视频资源提取和 STRM 文件生成功能。该系统能够帮助用户自动将 115 云盘中的视频资源转换为可在各种媒体播放器中使用的 STRM 文件。

## 系统架构

### 核心组件

1. **API 集成模块** (`115client.go`) - 负责与 115 云盘 API 进行交互
2. **目录树生成器** (`115client.go`) - 递归构建 115 云盘的完整目录结构
3. **视频资源解析器** (`parser.go`) - 从目录树中提取视频资源
4. **STRM 文件生成器** (`strm.go`) - 生成符合要求的 STRM 文件
5. **URL 编码工具** (`utils.go`) - 处理网络磁盘路径的编码
6. **错误处理与重试机制** (`retry.go`) - 提供可靠的错误处理和重试功能
7. **日志系统** (`log.go`) - 提供详细的日志记录

### 技术栈

- **后端**：Go 1.25.6
- **Web 框架**：Gin 1.11.0
- **数据库**：PostgreSQL
- **缓存**：Redis
- **配置管理**：YAML

## API 集成流程

### 115 云盘 API 集成

1. **认证流程**
   - 使用二维码登录方式
   - 通过 `authDeviceCode` 接口获取登录二维码
   - 轮询 `get/status` 接口检查登录状态
   - 获取授权码后通过 `oauth/access_token` 接口获取访问令牌

2. **目录树生成**
   - 使用 `files` 接口递归获取目录内容
   - 构建完整的层次化目录结构
   - 支持深度遍历所有子目录

3. **文件操作**
   - 使用 `files/download` 接口获取文件直链
   - 支持大文件和视频文件的处理

### API 端点

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/check` | GET | 无序校验接口，用于 STRM 文件 |
| `/login` | POST | 用户登录 |
| `/115/qrcode` | GET | 获取 115 登录二维码 |
| `/115/login/status` | GET | 检查登录状态 |
| `/115/files` | GET | 获取 115 文件列表 |
| `/115/direct-link` | GET | 获取文件直链 |
| `/strm/generate` | POST | 生成 STRM 文件 |
| `/strm/config` | GET/POST | STRM 配置管理 |

### 视频资源提取

解析器会从目录树中提取所有支持的视频格式文件：

- 支持的视频格式：MP4、MKV、AVI、MOV、WMV、FLV、WebM、M4V、TS、M2TS、ISO、IFO、VOB
- 自动过滤非视频文件
- 构建结构化的视频资源集合

### STRM 文件生成

STRM 文件生成器会：

1. 保持与 115 云盘相同的目录结构
2. 为每个视频资源生成对应的 .strm 文件
3. 在 STRM 文件中填充服务的无序校验接口 URL
4. 确保 URL 编码正确，特别是对于包含特殊字符的路径

## 使用指南

### 配置设置

1. **配置文件** (`config.yaml`)
   - 设置 115 云盘应用 ID 和密钥
   - 配置数据库和 Redis 连接信息
   - 调整日志级别和输出方式

2. **环境变量**
   - 支持通过环境变量覆盖配置文件设置
   - 推荐用于生产环境部署

### 基本使用流程

1. **启动服务**
   ```bash
   go run main.go 115client.go 115config.go auth.go db.go log.go redis.go parser.go strm.go utils.go retry.go
   ```

2. **登录认证**
   - 访问 `/115/qrcode` 获取登录二维码
   - 使用 115 手机 App 扫描二维码
   - 确认登录后系统会获取访问令牌

3. **生成目录树**
   - 系统会自动生成完整的 115 云盘目录树
   - 可通过 `/115/files` 接口查看文件列表

4. **提取视频资源**
   - 解析器会自动识别并提取视频资源
   - 支持过滤特定格式的视频文件

5. **生成 STRM 文件**
   - 调用 `/strm/generate` 接口触发 STRM 文件生成
   - 系统会在指定目录生成对应的 STRM 文件

### 高级功能

1. **增量更新** - 支持只更新新增或修改的文件
2. **自定义输出目录** - 可指定 STRM 文件的输出位置
3. **格式过滤** - 可配置只处理特定格式的视频文件
4. **错误监控** - 详细的错误日志和监控指标
