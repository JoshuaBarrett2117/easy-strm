## 测试优先级

### P0 - 核心功能（必须通过）
- 创建/更新/删除媒体源
- 获取文件列表
- 本地文件移动/复制/删除/重命名

### P1 - 重要功能
- 文件搜索
- 文件列表分页/排序/过滤
- 批量文件操作

### P2 - 次要功能
- 115 云端文件操作（需要真实账号）
- 路径校验
- 并发安全

### P3 - 性能测试
- 大量文件列表性能
- 并发操作性能

## 测试环境要求

### 数据库
- PostgreSQL 12+
- 测试数据库：`easy_strm_test`
- 需要创建测试表结构

### Redis
- Redis 6+
- 用于任务队列测试

### 本地文件系统
- Windows 系统
- 临时目录权限
- 测试文件创建/删除权限

### 115 账号（可选）
- 真实的 115 账号和 Cookie
- 用于云端文件操作测试
