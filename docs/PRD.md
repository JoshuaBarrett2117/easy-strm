# Easy-STRM 产品需求文档

## 一、项目概述

### 1.1 项目定位

Easy-STRM 是一款轻量、高效的 115 网盘文件直链提取与 .strm 媒体文件生成工具。

### 1.2 核心价值

- 极客能力平民化：将复杂的直链获取和批量生成操作封装进简洁 UI
- 性能与体验并重：异步任务调度、实时进度监控
- 技术可行性前置：成熟稳定的技术方案，不过度工程化

## 三、核心功能模块

### 3.1 基础支撑

| 功能 | 描述 |
| :--- | :--- |
| 账户鉴权 | 用户注册、登录、JWT Token 状态保持 |
| 配置中心 | 115 网盘授权状态（Cookie/Token）管理 |

### 3.2 核心业务 (直链与 STRM)

| 功能 | 描述 |
| :--- | :--- |
| 直链解析 | 精准提取 115 网盘目标文件的真实下载直链 |
| STRM 全量生成 | 对指定目录或全库一键批量生成 .strm 挂载文件 |
| STRM 增量同步 | 基于目录状态比对，仅对新增/变更文件生成 |

### 3.3 任务调度与监控

| 功能 | 描述 |
| :--- | :--- |
| 生命周期管理 | 任务创建、条件查询、手动删除 |
| 状态监控 | 实时进度、成功/失败状态、日志概览 |
| 定时任务 (Cron) | 定时调度任务统一接入「查看任务」页面 |

## 四、API 接口规范

### 4.1 认证相关

| 端点 | 方法 | 功能 |
| :--- | :--- | :--- |
| /login | POST | 用户登录 |
| /user/info | GET | 获取用户信息 |

### 4.2 115 云盘相关

| 端点 | 方法 | 功能 |
| :--- | :--- | :--- |
| /cloud115 | GET | 获取账号列表 |
| /cloud115/:id | GET/PUT/DELETE | 账号 CRUD |
| /115/login/channels | GET | 获取支持的登录渠道 |
| /115/qrcode | GET | 获取登录二维码 |
| /115/login/status | GET | 检查扫码登录状态 |
| /115/login/confirm | POST | 确认登录并保存凭据 |
| /115/files | GET | 获取文件列表 |
| /115/direct-link | GET | 获取文件直链 |

### 4.3 STRM 配置相关

| 端点 | 方法 | 功能 |
| :--- | :--- | :--- |
| /strm/config | GET/POST | 配置列表/创建 |
| /strm/config/:id | GET/PUT/DELETE | 配置详情/更新/删除 |
| /strm/config/:id/generate/full | POST | 全量生成 |
| /strm/config/:id/generate/incremental | POST | 增量生成 |

### 4.4 任务相关

| 端点 | 方法 | 功能 |
| :--- | :--- | :--- |
| /tasks | GET | 获取所有任务 |
| /strm/task/:task_id | GET | 获取任务详情 |
| /cron/task | GET/POST/PUT/DELETE | 定时任务管理 |

## 五、页面与交互设计

### 5.1 页面清单

1. **登录页** - 用户认证入口
2. **Dashboard** - 数据概览、任务监控
3. **115账号管理** - 云盘账号 CRUD、扫码登录
4. **STRM配置** - 生成规则配置、定时任务设置
5. **STRM生成器** - 手动触发生成任务
6. **用户中心** - 个人信息管理

### 5.2 交互规范

- 所有新增的定时调度任务必须统一收拢至「查看任务」页面
- 任务操作需有明确的进度反馈和状态提示
- 错误场景需有中文友好提示

## 九、边缘场景处理

| 场景 | 处理方案 |
| :--- | :--- |
| Cookie 失效 | 提示用户重新扫码登录 |
| 网络超时 | 自动重试 + 指数退避 |
| 接口限流 | 降级处理 + 用户提示 |
| 文件重名 | 追加时间戳区分 |
| 权限不足 | 中文错误提示 |
