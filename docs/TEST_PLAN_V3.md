## 一、测试概述与范围

### 1.1 测试目标
验证 V3.0 版本「115网盘 SHA1 秒传同步」功能的正确性、稳定性与性能表现，确保核心链路零 P0 上线。

### 1.2 测试范围

| 模块 | 优先级 | 说明 |
| :--- | :--- | :--- |
| 账号管理增强 | P0 | 账号类型/状态机/优先级 |
| SHA1 秒传同步服务 | P0 | Hash计算/布隆过滤器/秒传API/调度器 |
| 同步任务管理 | P1 | 任务统一到「查看任务」页面 |
| 消息通知集成 | P2 | Telegram/Server酱/Email |
| 自动清理与空间预警 | P2 | 清理策略/播放日志 |

### 1.3 测试环境

| 组件 | 规格 |
| :--- | :--- |
| PostgreSQL | 192.168.31.12:15432 |
| Redis | 192.168.31.12:16379 |
| 115 网盘 | 测试账号 x 3（resource/vip/both 各一） |

## 三、接口测试用例

### 3.1 账号管理 API

```bash
# TC-API-ACC-001：创建账号（account_type 枚举校验）
curl -X POST http://localhost:8080/api/cloud115
  -H "Content-Type: application/json"
  -d '{"account_type": "resource", "priority": 1, "status": "active"}'

# 预期：201 Created，返回账号信息

# TC-API-ACC-002：无效枚举值校验
curl -X POST http://localhost:8080/api/cloud115
  -H "Content-Type: application/json"
  -d '{"account_type": "invalid_type"}'

# 预期：400 Bad Request，错误信息包含 account_type

# TC-API-ACC-003：账号状态更新
curl -X PUT http://localhost:8080/api/cloud115/{id}/status
  -H "Content-Type: application/json"
  -d '{"status": "cooling"}'

# 预期：200 OK，status 更新成功
```

### 3.2 同步任务 API

```bash
# TC-API-TASK-001：创建秒传同步任务
curl -X POST http://localhost:8080/api/task
  -H "Content-Type: application/json"
  -d '{"type": "sync_transfer", "source_account_id": 1, "target_account_id": 2, "file_ids": ["file_123", "file_456"]}'

# 预期：201 Created，任务ID返回

# TC-API-TASK-002：查询任务列表（过滤类型）
curl http://localhost:8080/api/task?type=sync_transfer

# 预期：200 OK，仅返回 sync_transfer 类型任务

# TC-API-TASK-003：取消任务
curl -X DELETE http://localhost:8080/api/task/{id}

# 预期：200 OK，任务状态变为 cancelled

# TC-API-TASK-004：任务去重验证
curl -X POST http://localhost:8080/api/task
  -H "Content-Type: application/json"
  -d '{"type": "sync_transfer", "file_ids": ["file_123"]}'

curl -X POST http://localhost:8080/api/task
  -H "Content-Type: application/json"
  -d '{"type": "sync_transfer", "file_ids": ["file_123"]}'

# 预期：第二个请求返回任务已存在，不创建新任务
```

### 3.3 秒传服务 API

```bash
# TC-API-TRANSFER-001：触发秒传
curl -X POST http://localhost:8080/api/transfer/instant
  -H "Content-Type: application/json"
  -d '{"source_account_id": 1, "target_account_id": 2, "file_id": "file_123"}'

# 预期：200 OK，包含 cid 和 transfer_status

# TC-API-TRANSFER-002：秒传结果缓存查询
curl http://localhost:8080/api/transfer/cache?sha1={sha1}

# 预期：200 OK，返回缓存结果或 null
```

### 3.4 通知配置 API

```bash
# TC-API-NOTIFY-001：更新通知配置
curl -X PUT http://localhost:8080/api/notify/config
  -H "Content-Type: application/json"
```
