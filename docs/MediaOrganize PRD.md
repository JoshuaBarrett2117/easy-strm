# 媒体文件自动整理功能 需求文档

## 一、功能概述

### 1.1 模块定位

MediaOrganize（媒体自动整理）是 MediaManager 的核心扩展模块，旨在实现散落媒体文件的自动化归类与规范化命名。

### 1.2 核心价值

| 特性 | 描述 |
| :--- | :--- |
| 智能识别 | 基于文件名模式匹配 + TMDB 元数据双重校验 |
| 多维分类 | 支持按类型、地区、内容形式分类 |
| 灵活模板 | 电影与剧集独立命名规则 |
| 增量同步 | 仅处理新增文件 |
| 原子操作 | 移动+重命名事务组合 |
