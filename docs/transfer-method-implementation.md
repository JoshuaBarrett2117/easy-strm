# 秒传方式实现需求

## 需求背景

当前115driver秒传存在sig invalid问题，需要实现go115和alist两种替代秒传方式。

## 需求内容

### 1. 实现go115秒传方式

**调研任务**：
- 研究go115库的秒传API实现
- 确定秒传接口和参数

**实现任务**：
1. 在115client.go中添加go115秒传实现
2. 参考现有115driver的RapidTransferFile签名
3. 使用统一的函数签名便于切换

### 2. 实现alist秒传方式

**调研任务**：
- 研究alist的秒传API实现
- 确定秒传接口和参数

**实现任务**：
1. 在115client.go中添加alist秒传实现
2. 需要alist_url和alist_token配置
3. 使用统一的函数签名便于切换

### 3. 秒传方式切换逻辑

**实现任务**：
1. 修改直链API中的秒传调用逻辑
2. 根据Cloud115.TransferMethod选择对应的秒传实现
3. 实现秒传失败时的回退机制

### 4. 测试验证

**测试任务**：
1. 测试115driver秒传
2. 测试go115秒传
3. 测试alist秒传
4. 确定哪种方式可以正常工作

## 技术要求

1. 保持函数签名一致便于切换
2. 添加适当的日志便于调试
3. 保留回退逻辑确保直链获取成功
