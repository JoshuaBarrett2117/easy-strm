## 1. 项目基础需求

### 1.1 项目定位

Easy-STRM 是一款轻量、高效的 115 网盘文件直链提取与 `.strm` 媒体文件生成工具，面向“低门槛完成媒体挂载、管理、整理与任务调度”的使用场景。

### 1.2 核心价值
- 极客能力平民化：把复杂的直链、批量生成和媒体整理封装成可视化流程
- 性能与体验并重：异步任务调度、状态反馈、结果可追踪
- 技术可行性前置：优先选择成熟方案，不过度工程化

### 1.3 当前技术栈

| 组件 | 技术选型 |
| :--- | :--- |
| 后端框架 | Go + Gin |
| 前端框架 | Vue 3 + Element Plus |
| 数据库 | PostgreSQL/MySQL |
| 缓存 | Redis |
| 媒体服务器兼容 | Emby / Jellyfin / Plex（当前阶段聚焦 Emby） |

### 1.4 当前核心能力

| 模块 | 当前能力 |
| :--- | :--- |
| 认证与账户 | 登录、用户信息、115 账号管理、扫码登录 |
| STRM | 配置管理、全量生成、任务列表、定时任务 |
| 媒体管理 | 媒体源、本地/115 文件浏览、文件操作、TMDB 识别、重命名、整理入口 |
| 运维辅助 | Dashboard、日志中心、网络测试、系统设置 |

## 3. 当前迭代定义

### 3.1 当前迭代主题

当前迭代统一定义为：`MediaManager Beta`

### 3.2 当前迭代唯一主目标

优先把以下主链路做成稳定闭环：
`媒体源浏览 -> TMDB 识别 -> 重命名预览 -> 整理执行 -> 结果反馈`

### 3.3 当前迭代范围

- TMDB 识别与更名流程补全
- 批量任务反馈与结果展示
- 115 媒体源浏览与操作体验修正
- 测试补齐与文档补齐

#### Out of Scope

- 全新独立模块拆分
- 复杂 Watch Folder 实时监听
- 高级回滚系统
- 播放日志、空间清理、通知中心
- 大规模架构重构

## 4. 当前迭代需求清单

### REQ-001：MediaManager 操作闭环升级

目标：
- 在单页面内完成媒体源选择、文件浏览、TMDB 识别、重命名预览、整理执行与结果查看

关键要求：
- 增加整理主入口
- 支持状态筛选
- 明确区分识别、重命名、整理、删除操作
- 批量操作后展示成功、失败、跳过摘要
- 支持一键刷新当前目录

验收重点：
- 不跳转页面即可完成一次完整批量整理
- 失败项必须返回可读原因

### REQ-002：本地媒体整理闭环打通

目标：
- 把“本地媒体源 -> TMDB 识别 -> 重命名 -> 归档整理”做成 Beta 可用能力

关键要求：
- 支持源目录、目标目录、媒体类型、命名模板
- 支持预览后执行
- 支持 `copy` 与 `move`
- 支持 `skip`、`overwrite`、`suffix`
- 预览与执行结果保持一致

验收重点：
- 支持电影与剧集
- 批量整理结果可查阅且页面不阻塞

### REQ-003：TMDB 识别体验补全

目标：
- 从“可调用 API”升级为“可支撑日常整理”

关键要求：
- 单文件展示 Top 3 候选
- 批量识别跳过目录
- 识别结果缓存保留 7 天
- 支持手动搜索与绑定
- 识别结果写回文件列表

### REQ-004：重命名能力升级

目标：
- 让重命名能力具备可控、可预览、可批量的稳定体验

关键要求：
- 单文件重命名保留原扩展名
- 批量重命名先预览后执行
- 复用预设模板机制
- 补齐模板变量能力

### REQ-005：115 媒体源体验修正

目标：
- 让 115 场景“可浏览、可识别、可基础操作”

关键要求：
- 补齐目录导航体验
- 尽量统一本地与 115 字段
- 明确提示不支持能力
- 不承诺本期完成完整整理闭环

### REQ-006：任务反馈与可观测性补齐

目标：
- 降低“点了按钮但不知道发生了什么”的体验问题

关键要求：
- 批量识别、重命名、整理进入统一任务体系或统一结果面板
- 任务结果最少包含类型、时间、总数、成功数、失败数
- 支持查看失败项列表

## 5. 当前已确认边界摘要

以下结论为当前统一生效口径：
- `Beta 1` 包含 `115` 整理执行
- 批量整理采用异步任务化
- `TMDB` 默认展示 Top 3 候选并允许手动选择
- 默认整理策略为 `move`
- 失败项支持一键重试
- `115` 目标路径不存在时自动创建
- `115` 操作顺序为先重命名再移动
- 整理后目标目录自动写入 `STRM` 配置
- `STRM` 增量与整理任务合并展示
- 媒体服务器首期仅支持 `Emby`
- 刷新粒度按路径
- 每个媒体源允许绑定不同媒体库
