# 开发与测试

- 更新日期：2026-07-23
- 维护者：Codex

## 1. 当前开发基线

项目采用 Go 后端与 Vue 3 前端：

- 后端：Gin、PostgreSQL、Redis。
- 前端：Vue 3、Vite、Naive UI、Tailwind CSS。
- 自动化：Go test、Go vet、Vite build、Playwright 脚本。

修改代码时应保持 Controller、Service、DAO、Domain 的依赖方向；页面统一通过 `src/utils/api` 调用后端。

## 2. 默认验证命令

后端：

```powershell
Set-Location .\easy-strm
gofmt -w <本次修改的 Go 文件>
go test ./...
go vet ./...
```

前端：

```powershell
Set-Location .\easy-strm-front
npm run build
```

媒体整理关键交互：

```powershell
Set-Location .\easy-strm-front
npm run e2e:organize-preview-refresh
npm run e2e:organize-preview-cancel
```

运行 E2E 前需要准备可登录的后端、前端服务和隔离测试数据。

## 5. 外部依赖验证

以下能力需要真实账号或服务，单元测试和构建通过不能替代真实联调：

- 115 登录、文件操作、秒传和直链。
- TMDB 搜索、详情和图片下载。
- Emby 连接、媒体库列表和刷新。
- Telegram、Server 酱和 SMTP 通知。

验证外部能力时应使用隔离目录和测试账号，记录预期失败与真实缺陷的区别。

## 6. 高风险回归点

- 弹窗关闭、重新预览和再次执行时是否停止旧轮询。
- 本地与 115 路径、CID、pickcode 的语义是否混用。
- 冲突策略在预览和执行阶段是否一致。
- 复制模式不得删除源文件。
- Watch 任务是否有终态、取消和失败原因。
- STRM 内容、路径映射和直链 User-Agent 是否正确。
