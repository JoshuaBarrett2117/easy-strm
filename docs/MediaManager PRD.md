## 十三、需求确认汇总（最终版）

> 以下为基于 Q1-Q18 回答的最终需求确认

### 13.1 跨源操作确认

| 操作类型 | 范围 | 实现方式 |
|:---|:---|:---|
| 本地 → 115 | ✅ 支持 | 先计算 SHA1 秒传 |
| 115 → 本地 | ✅ 支持 | 直链下载 |
| 115 → 115 | ✅ 支持 | 内部秒传（已有 RapidTransferFile） |
| 跨源移动 | ✅ 支持 | 复制完成后需用户手动确认删除源文件 |

### 13.2 媒体识别确认

| 项目 | 确认内容 |
|:---|:---|
| 识别精度 | 返回 Top 3 候选结果 + 自动消歧 |
| 媒体类型 | 电影、剧集、动漫（复用剧集规则） |
| 缓存策略 | 数据库缓存 7 天 + 支持手动刷新 |
| API Key | 用户自行在设置页填写 |

### 13.3 更名系统确认

| 项目 | 确认内容 |
|:---|:---|
| 预设方案 | 支持多个预设方案 + 用户自定义模板 |
| 预览编辑 | 允许手动修改预览文件名（不校验） |
| 冲突处理 | 提示用户选择覆盖与否，不覆盖则追加序号 |

### 13.4 自动整理确认

| 项目 | 确认内容 |
|:---|:---|
| 触发方式 | 手动 + 定时任务 + 文件夹监控 |
| 监控方案 | 本地文件夹用 fsnotify 实时监控，115 用定时轮询 |
| 删除机制 | 直接删除，不保留到回收站 |

### 13.5 任务队列确认

| 项目 | 确认内容 |
|:---|:---|
| 执行方式 | 后台异步执行，提交后显示"执行中" |
| 进度展示 | 任务列表统一管理进度 |

### 13.6 媒体服务器联动

| 项目 | 确认内容 |
|:---|:---|
| 联动方式 | 支持 Jellyfin/Emby API 自动刷新媒体库 |
| 触发时机 | 整理任务完成后自动触发 |

### 13.7 与 STRM 模块整合

| 项目 | 确认内容 |
|:---|:---|
| 整合方式 | MediaManager 整理后的文件，可快速触发 STRM 生成 |

## 十四、技术实现要点

### 14.1 核心组件

```
MediaManager
├── MediaSourceService     # 媒体源管理
├── FileBrowserService     # 文件浏览（同源/跨源操作）
├── TmdbService            # TMDB API 集成 + 缓存
├── RenameService          # 更名规则 + 预览执行
├── OrganizeService        # 自动整理规则 + 执行
├── MediaServerService     # Jellyfin/Emby API 联动
└── TaskExecutor           # 异步任务执行器
```

### 14.2 复用现有组件

| 组件 | 复用方式 |
|:---|:---|
| 115client.go | 复用 CopyFile、RapidTransferFile、GetFileDirectLink |
| task.go | 复用 Redis 任务队列 |
| cron.go | 复用 Cron 调度器 |
| parser.go | 复用/扩展视频文件解析逻辑 |
| transfer_scheduler.go | 复用熔断器、限流器 |

### 14.3 新增依赖

| 依赖 | 用途 |
|:---|:---|
| github.com/fsnotify/fsnotify | 本地文件夹实时监控 |
| github.com/jellyfin/org.jellyfin.api/v3 | Jellyfin API 客户端 |
| github.com/rexlann/tmdb | TMDB API 客户端（或自行实现） |

### 14.4 优先级排期

| Phase | 功能 | 依赖关系 |
|:---|:---|:---|
| **Phase 1** | 媒体源配置 + 文件浏览基础 CRUD | 独立开发 |
| **Phase 1** | 同源文件操作（移动/复制/删除/重命名） | 依赖 Phase 1 |
| **Phase 2** | TMDB 集成 + 单文件识别 + Top3 候选 | 依赖 Phase 1 |
| **Phase 2** | 更名预览 + 执行 + 手动编辑 | 依赖 TMDB 集成 |
| **Phase 3** | 跨源复制（本地↔115） | 依赖 TMDB 集成 |
| **Phase 3** | 批量 TMDB 识别 + 自动消歧 | 依赖 TMDB 集成 |
| **Phase 4** | 自动整理规则 + 执行 | 依赖更名系统 |
| **Phase 4** | 文件夹监控（本地 fsnotify / 115 轮询） | 独立开发 |
| **Phase 5** | Jellyfin/Emby API 联动 | 依赖整理任务 |
| **Phase 5** | 定时整理任务 | 依赖 Cron 调度器 |

## 十五、风险评估与建议

### 15.1 高风险项

| 风险 | 缓解方案 |
|:---|:---|
| TMDB API 限流 | 用户自备 Key，设计缓存策略 |
| 115 API 风控 | 复用现有 TransferScheduler 熔断机制 |
| 跨源移动数据丢失 | 采用"复制+用户手动确认删除"策略 |

### 15.2 建议功能（Phase 2+）

| 功能 | 价值 |
|:---|:---|
| 操作日志审计 | 记录所有文件操作的详细信息 |
| 回滚机制 | 对高风险操作提供回滚能力 |
| 任务中断与恢复 | 对大文件传输支持暂停/续传 |
